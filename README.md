# Velvet

A dark velvet purple theme for the Claude desktop and mobile apps. Soft plum and rose light drifts slowly through deep violet behind the conversation, with a fine film grain. The palette tints every surface in plum with a lavender accent and rose highlights. It is drawn natively at 2560×1440 and scales to any screen.

It comes with five backdrops:

| Backdrop | What it is |
| --- | --- |
| `classic` | The default: drifting plum and rose glows with a soft silk ribbon |
| `satin` | The ribbon sways, and a sweep of light runs along it every 13 seconds |
| `glass` | Frosted glass forms float in the glow and bend the light behind them |
| `motes` | Soft, warm specks of light rise slowly at three depths |
| `silk` | Six ribbons of plum, violet and rose light flowing at different depths |

## Install

At the prompt of a terminal session:

```
/plugin install velvet --marketplace reversedPF/velvet-claude-theme
```

Answer `y` to add the marketplace, then pick a scope (user scope loads it in every session).

From a shell:

```bash
claude plugin install velvet --marketplace reversedPF/velvet-claude-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `reversedPF/velvet-claude-theme`, then Add plugin.

## Use

Type these in the chat:

- `/velvet classic`, `/velvet satin`, `/velvet glass`, `/velvet motes`, `/velvet silk` switch the backdrop
- `/velvet still` holds the motion still, `/velvet move` starts it again
- `/velvet blur 0-64` sets how much the app frosts its panels over the backdrop (default 6; higher is softer and easier to read over)
- `/velvet` alone says what is on now

Your choice is remembered across sessions.

## Troubleshooting

- The theme draws in the Claude desktop and mobile apps, not in a terminal or editor.
- On macOS, if the colors change but the backdrop does not show, turn off **Reduce transparency** (System Settings → Accessibility → Display) and **Reduce motion** (Accessibility → Motion), then quit and reopen Claude.

## Changing the art

The scenes in `hooks/scenes.ts` are generated by `tools/generate-scenes.js`:

```bash
node tools/generate-scenes.js ./out hooks/scenes.ts
```

It also writes each scene as a standalone SVG into `./out` for previewing in a browser. Keep each scene under 131,072 characters.
